# FunPay Monitor

VK-бот для мониторинга цен на игровом маркетплейсе [FunPay](https://funpay.com): следит за лотами и игровой валютой, хранит историю цен и присылает уведомления, когда цена падает ниже порога, падает на N% или обновляет исторический минимум.

> Учебный проект (итоговый/дипломный). Текущий статус: каркас репозитория (неделя 1 плана).

## Стек

Python 3.12 · vkbottle · SQLAlchemy 2.0 (async) · PostgreSQL 16 · Alembic · APScheduler · httpx + BeautifulSoup · matplotlib · Docker Compose · pytest · ruff

## Быстрый старт

### Через Docker

```bash
cp .env.example .env
docker compose up -d db
```

`bot` и `worker` пока запускаются как заглушки: бот подключится к VK на второй неделе.

### Локально

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"

pytest          # тесты
ruff check .    # линтер
```

## Переменные окружения

| Переменная | По умолчанию | Описание |
|---|---|---|
| `VK_GROUP_TOKEN` | — | Ключ доступа сообщества VK (Long Poll) |
| `VK_GROUP_ID` | `0` | ID сообщества |
| `DATABASE_URL` | `postgresql+asyncpg://funpay:funpay@localhost:5432/funpay` | DSN базы данных |
| `LOG_LEVEL` | `INFO` | Уровень логирования |
| `PARSE_INTERVAL_MINUTES` | `15` | Интервал опроса FunPay |
| `REQUEST_DELAY_SECONDS` | `3` | Пауза между HTTP-запросами к FunPay |
| `ALERT_COOLDOWN_HOURS` | `6` | Минимальный интервал между алертами по одной подписке |

## Настройка сообщества VK

1. Создать сообщество → «Управление» → «Сообщения сообщества»: включить.
2. «Работа с API» → Long Poll API: включить; создать ключ доступа сообщества.
3. Ключ положить в `.env` (`VK_GROUP_TOKEN`), ID сообщества — в `VK_GROUP_ID`.
4. Пользователь должен написать боту первым — VK не даёт сообществу писать тому, кто не начинал диалог.
