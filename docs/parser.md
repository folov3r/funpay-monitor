# Парсер FunPay

## Интерфейс

`app/parsers/base.py` описывает контракт источника данных:

```python
class BaseParser(ABC):
    async def fetch_category(self, url_path: str) -> ParsedCategory: ...
    async def aclose(self) -> None: ...
```

`ParsedCategory` содержит `CategoryInfo` и список `Offer`. Благодаря этому
`MonitoringService` не знает, откуда пришли данные.

## Разбор страницы

`FunPayParser` поддерживает `/chips/{id}/` и `/lots/{id}/`:

- офферы — `a.tc-item`;
- цена — первый вложенный `div` внутри `.tc-price`;
- количество — `.tc-amount`, суффикс `кк` умножается на 1 000 000;
- сервер — атрибут `data-server` и `.tc-server`;
- продавец — `data-user` или ссылка на профиль в `.avatar-photo`;
- промо — класс `offer-promo`.

Название категории и игры берутся из заголовка страницы. JSON-LD `lowPrice`
сознательно не используется: на проверенной странице он расходился с таблицей
(20.41 против фактических 14.54).

Сервер `"*"` (лот подходит любому серверу) сохраняется как
`funpay_server_id=0`, имя `"Любой"`. Подписка «любой сервер» хранит `server_id=NULL`.

## Вежливость к FunPay

- между запросами выдерживается `REQUEST_DELAY_SECONDS` (по умолчанию 3 с);
- при 429 и 5xx выполняется повтор с backoff;
- реалистичный User-Agent;
- интервал планировщика — 15 минут и больше;
- скачиваются только публичные страницы, без авторизации.

## Тесты

Тесты парсера работают на сохранённых HTML-страницах в `tests/fixtures/funpay/`,
поэтому не зависят от сети и позволяют заметить смену вёрстки после обновления
фикстур.

```bash
python scripts/parse_once.py /chips/30/
python scripts/parse_once.py https://funpay.com/lots/13/
```

Скрипт печатает категорию, число офферов и минимальную цену — быстрый способ
проверить парсер без БД и бота.

## Ограничения

- FunPay может изменить вёрстку; тогда `parse_runs` получит `error` с нулём
  офферов, а не «тихий» успех.
- Промо-лоты могут искажать минимум; флаг `is_promo` сохраняется, но в текущем
  MVP минимум считается по всем офферам.
- Парсер не обходит капчу и не использует авторизацию.
