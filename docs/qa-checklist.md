# QA-чеклист

Чеклист для ручной проверки перед защитой. Отмечайте пункты после каждого
релиза-кандидата.

## Подготовка

- [ ] `.env` заполнен: `VK_GROUP_TOKEN`, `VK_GROUP_ID`, `VK_ADMIN_IDS`.
- [ ] `python scripts/check_vk.py` показывает сообщество и Long Poll сервер.
- [ ] `docker compose up --build -d` завершился без ошибок.
- [ ] `docker compose ps` — `db`, `bot`, `worker` запущены.
- [ ] В логах `migrate` есть `Running upgrade` без ошибок.
- [ ] Пользователь VK написал сообществу первым.

## Базовые команды

- [ ] `/start` присылает приветствие и клавиатуру.
- [ ] `/help` показывает список команд.
- [ ] Неизвестный текст вне диалога даёт подсказку, а не молчание.

## Добавление подписки

- [ ] `/add` без ссылки просит ссылку.
- [ ] `/add https://funpay.com/chips/30/` парсит категорию.
- [ ] Ссылка без команды работает так же.
- [ ] Неверная ссылка даёт понятную ошибку.
- [ ] Кнопки серверов отображаются; «Любой» работает.
- [ ] Название сервера можно ввести текстом.
- [ ] Режим `abs` просит рубли, `pct` — проценты, `lowest` — сразу подтверждение.
- [ ] Порог `1 450,50` принимается.
- [ ] Порог `0`, `-5`, `abc` и `101%` отклоняются.
- [ ] «Отмена» на каждом шаге сбрасывает диалог.
- [ ] Подтверждение сохраняет подписку и показывает её номер.

## Список и статистика

- [ ] `/list` показывает подписки, сервер, условие и текущую цену.
- [ ] Кнопка «Статистика #N» открывает `/stats N`.
- [ ] `/stats N` присылает текст и PNG-график.
- [ ] `/stats` без номера показывает список.
- [ ] `/stats 999999` сообщает, что подписка не найдена.
- [ ] `/unsubscribe N` удаляет подписку, повторный вызов не падает.
- [ ] Кнопка «Удалить #N» работает.

## Алерты

- [ ] Подписка с заведомо высоким порогом `abs` срабатывает после парсинга.
- [ ] Алерт приходит с графиком.
- [ ] Повторный прогон в течение 6 часов не дублирует уведомление.
- [ ] После изменения порога и `/reparse` алерт срабатывает снова.
- [ ] `pct` срабатывает только при падении больше порога.
- [ ] `lowest` не срабатывает на первом снапшоте.
- [ ] Текст алерта содержит категорию, цену, условие и номер подписки.

## Админка

- [ ] `/status` доступен админу и показывает счётчики.
- [ ] `/status` отклоняется для обычного пользователя.
- [ ] `/reparse 3` перепарсивает категорию.
- [ ] `/reparse /chips/30/` импортирует категорию по ссылке.
- [ ] `/reparse` без аргумента даёт подсказку.
- [ ] После `/reparse` в `/status` виден свежий запуск.

## Ошибки и устойчивость

- [ ] Остановить `worker`, запустить снова: зависшие `running` становятся `error`.
- [ ] Временно указать неверный путь категории: в `parse_runs` появляется `error`.
- [ ] Остановить `db`: бот и воркер логируют ошибку и не падают молча.
- [ ] Очистить `VK_GROUP_TOKEN` в воркере: парсинг продолжается, алерты отключены.
- [ ] Перезапустить бота во время `/add`: диалог начинается заново, данные в БД целы.

## Перед защитой

- [ ] CI на последнем коммите зелёный.
- [ ] `pytest` локально проходит.
- [ ] `mkdocs build --strict` проходит.
- [ ] Свежий скриншот `/list`, `/stats` и алерта.
- [ ] Записано демо-видео на случай проблем с сетью.
- [ ] Проверен сценарий демо на чистой базе.
- [ ] В презентации актуальные цифры (тесты, таблицы, команды).
