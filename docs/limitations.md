# Ограничения

## Функциональные

- нет мобильного приложения и VK Mini App;
- VK-бот остаётся дополнительным каналом и не входит в desktop-сборку;
- поддерживаются только публичные категории FunPay, без авторизации;
- второй источник данных (Steam) не реализован, но предусмотрен `BaseParser`;
- нет очереди уведомлений: при большом числе подписок потребуется ограничение
  скорости и повторные попытки.

## Данные

- офферы перезаписываются при каждом разборе, история хранится только в
  агрегированных снапшотах;
- минимум считается по всем офферам, включая промо; флаг `is_promo` сохранён
  для будущей фильтрации;
- JSON-LD `lowPrice` не используется из-за расхождения с таблицей;
- SQLite рассчитана на одного пользователя и один экземпляр приложения:
  сетевого доступа к базе нет.

## Эксплуатация

- одновременно может работать только один экземпляр приложения: порт `8765`
  занят;
- нет автоматических обновлений и бэкапов базы;
- нет внешнего health-check и оповещения администратора о сбоях;
- установщик собирается только под текущую ОС: Windows-пакет — на Windows,
  Linux-пакет — на Linux;
- установщик Windows не подписан сертификатом, поэтому SmartScreen может
  показать предупреждение.

## Уведомления

- на Linux нужен работающий демон уведомлений (`notify-send`);
- на Windows используется `winotify`; если пакет недоступен, уведомление
  остаётся только в журнале приложения;
- системное уведомление содержит текст без графика: график доступен в
  интерфейсе и в VK-канале.

## VK-бот

- сообщество может писать только пользователю, который сам написал первым;
- лимиты VK API не тестировались под высокой нагрузкой;
- для живого запуска нужен ключ доступа сообщества и включённый Long Poll.

## Правовые замечания

Проект учебный. Он разбирает только публично доступные страницы FunPay с умеренной
частотой и не обходит авторизацию, капчу или платные ограничения. Перед публичным
запуском нужно свериться с правилами FunPay и VK, а также с законодательством о
персональных данных: VK-канал хранит VK id и имя пользователя.

## Дальнейшее развитие

1. Второй парсер (Steam) как демонстрация расширяемости.
2. Аналитика: лучшие продавцы, сравнение серверов, разброс цен.
3. Очередь уведомлений и ограничение скорости.
4. Автозапуск при входе в систему, бэкапы и автообновления.
5. Опционально — VK ID OAuth и личный кабинет.
