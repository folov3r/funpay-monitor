# Команды бота

## Пользовательские

| Команда | Действие |
|---|---|
| `/start` | приветствие и главное меню |
| `/help` | справка |
| `/add` | начать добавление подписки |
| ссылка FunPay | то же, что `/add <ссылка>` |
| `/list` | активные подписки и текущие цены |
| `/stats <id>` | статистика и график за 7 дней |
| `/unsubscribe <id>` | мягко удалить подписку |
| «Отмена» | выйти из диалога |

## Админские

Доступны только VK id из `VK_ADMIN_IDS`.

| Команда | Действие |
|---|---|
| `/status` | категории, пользователи, подписки, офферы, последние запуски |
| `/reparse <id>` | перепарсить категорию по внутреннему id |
| `/reparse <ссылка>` | загрузить категорию с FunPay и проверить алерты |

## Сценарий `/add`

1. Бот просит ссылку, если её нет в сообщении.
2. Парсит категорию на месте и создаёт её в БД, даже если воркер её ещё не видел.
3. Предлагает серверы кнопками или «Любой».
4. Спрашивает режим: ниже порога, падение в %, исторический минимум.
5. Для `abs` и `pct` просит числовой порог.
6. Показывает подтверждение и сохраняет подписку.

Состояние диалога хранится в state dispenser vkbottle (в памяти процесса) и не
переживает перезапуск. Это осознанное упрощение MVP: незавершённый диалог можно
начать заново командой `/add`.

## Примеры

```
/add https://funpay.com/chips/30/
/chips/30/
/stats 2
/unsubscribe 2
```

Порог можно вводить с пробелами и запятой: `1 450,50`.

## Клавиатуры

- главное меню: «Добавить», «Мои подписки», «Помощь»;
- серверы: до 8 кнопок + «Любой» + «Отмена»;
- режимы: «Ниже порога», «Падение в %», «Исторический минимум»;
- список подписок: «Статистика #N» и «Удалить #N»;
- подтверждение: «Сохранить» и «Отмена».

Inline-кнопки отправляют обычный текст, поэтому обрабатываются теми же
message-хендлерами — без callback-событий `message_event`.
